Patch Approval

Runs the review, then pauses so you can approve or reject each proposed fix. Approved fixes are applied to a throwaway copy of the merged code and fully re-tested. Your own files are never changed. Back to dashboard

No AI key is configured, so root causes come from simple built-in rules and no fixes can be written. Put GEMINI_API_KEY=... in .env, restart the server, and run python -m tools.check_llm to confirm it works.
